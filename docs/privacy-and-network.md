# 隐私与网络边界

本文描述当前本地优先实现的数据落盘、出站请求、凭据和备份边界。它是实现说明，不替代所选招聘平台或模型服务商的隐私条款。

## 本机保存的数据

OfferFlow 使用独立应用标识 `io.github.ye-feng0510.offerflow` 和 Tauri 的平台目录 API，不在代码或文档中假定固定的 OS 路径：

- `app_config_dir/app_config.yaml`：招聘筛选、话术、浏览器路径、LLM 地址/模型/超时和可选简历上下文等配置。
- `app_data_dir/data/`：`job_details.json`、`chat_messages.json`、`interview_analyses.json` 和 `user_resumes.json`。
- `app_data_dir/browser-profile/`：默认的独立 Chromium 资料目录，可能含招聘平台登录状态和网站存储。
- `app_data_dir/rpa.log`：运行状态与错误日志。
- `app_data_dir/backups/`：配置版本升级时生成的保护副本。

正常配置和 DAO JSON 写入使用临时文件及原子替换。业务记录和导出的备份不是加密文件；不要把“本地保存”等同于加密保护。

## 旧版迁移与隔离

旧版应用标识为 `me.pgthinker.fj`。OfferFlow 不会自动接管旧目录；只有用户明确选择迁移时，才复制支持的配置与求职 JSON 数据到新的应用目录。旧数据和旧系统凭据保留，不执行移动或删除。

浏览器资料目录重新创建，不复制旧 Cookie 或登录状态；使用招聘平台前需要重新登录。模拟面试的 localStorage、原始 PDF 与图片也不复制，需要时请重新导入。应用数据目录及系统凭据命名空间的隔离不等于对所有历史 WebView 存储自动迁移。

迁移仅允许在新应用尚未完成引导且没有业务记录时执行。导入前校验支持的配置版本与数据结构，拒绝符号链接和 Windows 重解析点；可恢复的文件或凭据写入失败会尝试回滚本次改动。它不是跨文件崩溃事务，断电或强制结束进程后可能需要从暂存目录手动恢复。迁移前请关闭旧应用，避免读取到写入中的数据。

浏览器调试端口使用独立的 `19876–19880` 范围，且不会接管缺少本应用管理记录的 CDP 会话。不要手动把浏览器目录改回旧应用目录。

## 发送给所配置 LLM 的数据

只有在用户主动获取模型列表、测试连接或运行 AI 功能时，应用才访问当前配置 provider 的模型服务地址：

- 模型列表：按 provider 调用对应列表接口；OpenAI (Completions) 与 OpenAI (Responses) 通常访问 `<base_url>/models`，Ollama 使用原生模型列表接口。
- 短连接测试：向当前 provider 的生成接口发送固定的简短测试提示。OpenAI (Completions) 使用 `<base_url>/chat/completions`，OpenAI (Responses) 使用 `<base_url>/responses`，Ollama 使用原生 `/api/chat`。
- 流式测试：向当前 provider 的流式生成接口发送固定测试提示并读取 SSE 或 provider 原生流式响应。
- 打招呼/岗位分析：可能发送岗位标题、公司、薪资、地点、岗位描述和配置的提示词。
- 回复生成/沟通调试：可能发送聊天历史、岗位描述、背景上下文和提示词。
- 简历相关 AI：会发送用户选择或编辑的简历内容、问题、回答或模拟面试历史。
- 开启“注入简历上下文”后，自动打招呼或回复也可能携带配置中的简历内容。

请求使用配置的模型 ID 和所选协议要求的认证方式。备用模型可能接收同一业务上下文；关闭简历注入只约束相关自动化链路，不阻止岗位分析和模拟面试使用显式提供的简历。应用无法控制远程服务商如何保存、训练或转发这些内容。对敏感数据，应优先使用本机 Ollama，或选择有合适数据政策的服务商并最小化上下文。

## 招聘平台流量

仅在用户执行环境检查、扫码登录、抓取已沟通过岗位、单轮/周期求职或回复未读时，自动化浏览器访问以下站点：

- BOSS 直聘：`zhipin.com` / `www.zhipin.com`。
- 猎聘：`liepin.com` / `www.liepin.com`。

这些请求由受控 Chromium 会话发出，行为和普通浏览器访问一样会受平台 Cookie、风控、账号状态及服务条款约束。应用不把招聘数据转发到原项目业务服务器。

## 用户主动打开的链接

“关于与数据”中的仓库、Apache-2.0 许可和文档按钮会调用系统默认浏览器。用户点击简历或其他内容中的外部链接时，也可能由系统浏览器访问目标站点。这些导航由用户触发，不是后台遥测。

## 密钥存储与优先级

模型密钥的解析顺序为：

1. 系统钥匙串/凭据库中的 `offerflow` / `llm_api_key`。
2. 非空的环境变量 `OFFERFLOW_LLM_API_KEY`。
3. 非空的旧环境变量 `FUCKJOB_LLM_API_KEY`（兼容回退）。
4. 无密钥。

若读取系统凭据库失败，但上述环境变量之一是非空值，应用仍按此顺序使用环境变量并将凭据来源报告为“环境变量”。若凭据库读取失败且环境变量缺失或为空，应用会提示配置 `OFFERFLOW_LLM_API_KEY`。旧版 `fuck_job` / `llm_api_key` 仅用于用户明确确认的迁移复制，不作为运行时自动回退；旧条目不会被删除。

界面“保存凭据”写入系统凭据库；“清除模型密钥”只删除该凭据库条目，不修改环境变量。Tauri 命令只返回“是否配置”和来源，不返回明文密钥。Ollama 默认不要求密钥；其它 provider 均需要先保存 API Key。

## 日志与脱敏

`app_data_dir/rpa.log` 记录时间、级别、平台和操作状态。写入前会对 Authorization、API Key、token、Cookie、简历正文、聊天正文和 prompt 等常见键值形式做脱敏。错误对 UI 只返回分类码和稳定的用户消息；Rust 内部诊断详情不会序列化到 Tauri 命令结果。模型服务的非成功 HTTP 响应及 SSE/JSON 解析错误仅在内部保留 HTTP 状态、经过字符和长度约束的服务商错误 code/type，以及解析类别和位置，不保留任意响应正文。

脱敏是纵深防御，不应视为任意文本的完美数据防泄漏。第三方页面或库错误可能包含意外格式；分享日志前仍应人工检查。可以在“关于与数据”中清空日志。

## 备份内容与排除项

`.fjbackup` 是未加密 ZIP，包含版本和数量清单、岗位、聊天、分析、方案快照、用户简历数据，以及可选的配置文件。当前实现不包含 SHA-256 校验清单，也不对整个配置文件进行通用敏感字段清洗。

以下内容明确不进入导出备份：

- 系统钥匙串/凭据库、`OFFERFLOW_LLM_API_KEY` 和兼容变量 `FUCKJOB_LLM_API_KEY`。
- `rpa.log`。
- `browser-profile/` 及招聘平台登录态/Cookie。
- 迁移备份、自动回复额度记录、人工待办、模拟面试 localStorage、原始 PDF 和图片文件。

备份导入与首次旧版迁移是两条不同流程。备份导入按指定名称读取记录，当前没有跨文件事务回滚；部分缺失或格式错误的数据可能被跳过。“覆盖”会替换岗位、聊天、分析及方案快照集合，用户简历则覆盖同名项并保留本地独有项。请仅导入可信备份，并在恢复前另外保存现有数据；导入配置后建议重启。

## 明确不存在的后台连接

当前运行时不包含：

- 原项目业务服务器、旧账号/登录/注册、积分或兑换 API。
- 遥测、崩溃上报或云端同步。
- DashScope/其他提供商的联网搜索开关，或任何 Web 搜索功能。

## 自动更新

独立发行版本暂未启用自动更新。启动和手动检查都不会发送更新网络请求；手动检查仅显示“独立发行版本暂未启用自动更新”，不会声称已是最新版本。下载、安装与重启入口均已停用。

Tauri 配置已移除上游更新地址与公钥，`bundle.createUpdaterArtifacts` 为 `false`。当前独立仓库 [Ye-feng0510/OfferFlow](https://github.com/Ye-feng0510/OfferFlow) 尚无发行包；只有用户主动打开仓库链接时才访问 GitHub。启用独立签名与发版前的要求见 [发行与更新状态](updater-release.md)。

## 自行审计

在仓库根目录运行：

```bash
pnpm check:network
```

该脚本扫描前端、Rust 运行时、Tauri/Cargo 配置、官网、GitHub 工作流、`package.json` 和 `build.sh`，并在发现原服务器、旧接口或硬编码搜索时失败。测试文件、文档、依赖锁和构建产物不会被当成运行时。

可补充查看所有 URL 和敏感日志调用：

```bash
rg -n --glob '!node_modules/**' --glob '!src-tauri/target/**' 'https?://' src src-tauri/src
rg -n --glob '!src-tauri/target/**' 'logger::|Authorization|api[_-]?key|token|cookie' src-tauri/src
```
